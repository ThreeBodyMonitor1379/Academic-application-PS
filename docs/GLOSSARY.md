# 术语词典

| 术语 | 本项目中的含义 |
|---|---|
| Prompt-controlled genre | PS/SOP 标签不自动决定内容；当期官方 prompt、补充说明、受众和硬约束共同定义任务。 |
| Target | 已核对的项目、学位类型、受众、问题和提交约束。 |
| Evidence | 能回到用户材料或明确本人确认，并限定了个人/团队归因与允许表述强度的事实。 |
| Trajectory | 过去如何形成当前问题意识或方法，当前又如何通向一个有依据、非绑定的未来方向。 |
| Fit | 申请者目标与项目当期、可核验机制的因果连接，以及有过去证据支持的有限贡献。 |
| Boundaries | 不得猜测的个人事实、隐私选择、尚未核实的要求、不授权的外部动作和待解决风险。 |
| Readiness | 五个维度的模糊度评分；均值不高于 `0.20` 且每个维度不高于 `0.25` 才通过证据门禁。通过后仍须批准中文大纲。 |
| Claim ceiling | 由方案来源、本人修改、验证阶段、指标口径和个人/团队归因共同决定的最大可辩护主张。 |
| Outline approval | 申请人对某个中文证据大纲版本的明确确认；这是英文起草前独立于 readiness 的内容所有权门禁。 |
| Evidence paragraph | 一个执行模式：单一主张 → 本人行动 → 可追溯证据 → 允许能力结论 → 未来用途。它是编排器内部 reference，不是第四个 skill。 |
| Personal hook | 可选的相关个人经历开头；必须服务当前方向和未来计划，不要求创伤或敏感披露。 |
| Remedy | 弱项或转折后的真实补救行动、学习结果和当前准备度，而非为过去扩张借口。 |
| User override | 用户可知情接受部分证据风险并提前结束质询；agent 必须保留风险，不得猜测事实，也不得用 override 跳过中文大纲批准。 |
